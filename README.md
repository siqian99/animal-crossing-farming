# 无人岛料理收益管家

《集合啦！动物森友会》的非官方料理与种植收益工具。输入食材数量、已学配方或农田面积，计算如何安排料理与种植，让收成赚更多铃钱。

**[打开网页版](https://brilliant-speculoos-a263e0.netlify.app/)** · **[反馈问题](https://github.com/VickieZhou/acnh-cooking-profit/issues)**

可在手机和电脑浏览器中使用，无需注册。计算在浏览器中完成，个人记录保存在当前设备。

## 功能

| 功能 | 用途 |
| --- | --- |
| 库存原料 | 输入作物、鱼、海产、水果及加工原料的数量，规划料理组合与直接出售的余料 |
| 农田分配 | 输入土地格数、每株预计产量和各作物最低株数，计算种植分配与每轮收获收益 |
| 我的料理手册 | 勾选已学会的料理 DIY，只使用已解锁配方计算；支持搜索、系列顺序与拼音顺序 |
| 制作清单 | 按加工和料理顺序制作；支持打勾、记录部分完成份数，以及恢复之前的清单 |
| 岛屿设置 | 设置今日双倍料理、出售渠道、特产水果等出售条件 |

包含 **141 个料理与加工配方**，提供两种计算模式：

- **总收益最高**：最大化料理与剩余原料出售后的总收入。
- **省制作批次**：在保留指定收入比例的前提下，尽量减少制作批次。可选择最高收入的 50%–100%；同一配方最多 10 次计为一批。

结果会显示总收入、相比原料直接出售多赚的铃钱与百分比，以及加工品的后续用量和直接出售数量。

## 使用方法

首次使用时，指引会进入对应页面，淡化其他区域并突出当前功能；可随时点击「使用指引」重新查看。

1. 在「我的料理手册」勾选已学会的料理 DIY，或用「全部标记」勾选全部 141 个。每次勾选会自动保存，也可点击「保存配方」确认。
2. 在「岛屿设置」选择自己的出售条件。
3. 在「库存原料」填写现有食材，或在「农田分配」填写土地与产量。
4. 选择收益模式，生成方案。
5. 按制作清单执行：完成一部分时填写已做份数，全部完成时打勾；按「直接卖」出售剩余材料。

库存首次使用默认为 0；“一键清空”只清空原料数量，不清除配方与制作进度。配方支持系列顺序和拼音顺序。制作进度按钮按整批记录：面粉、全麦面粉、砂糖、黑糖每批 100 份，其他料理每批 10 份；不足一批时可手动填写。

面粉、砂糖等加工配方一次会产出多份，清单按实际产出份数记录进度。余料售价已计入总收入；勾选进度不会自动扣减手动输入的库存。

### iPhone 使用

用 **Safari** 打开网页版，选择 **分享 → 添加到主屏幕**，即可从桌面图标进入。首次完整加载且缓存成功后，可离线使用已缓存资源。

### 数据保存与备份

库存、已学配方、农田、设置和制作进度只保存在当前浏览器。不同设备、浏览器及网址之间不会自动同步。

在「数据与使用说明」中导出或导入 JSON 备份。换设备、迁移网址或清理浏览器数据前，请先导出备份；浏览器清理或回收网站数据可能移除记录。

「全部取消」已学配方前需要确认。其他食材与已加工原料、每种作物最低株数均直接显示，无需展开。

## 下载与本地运行

下载仓库：点击 **Code → Download ZIP** 并解压，或使用 Git：

```sh
git clone https://github.com/VickieZhou/acnh-cooking-profit.git
cd acnh-cooking-profit
```

需要 Node.js 20 或更新版本：

```sh
npm start
```

打开 <http://127.0.0.1:4173/>。项目没有 npm 依赖，不需要执行 `npm install`。

也可使用 Python 3：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

请通过本地 HTTP 服务运行；直接双击 `dist/index.html` 无法正常使用 Web Worker 计算。

## 开发与贡献

项目采用原生 HTML、CSS、JavaScript，以及 HiGHS 的 WebAssembly 求解器，无需前端构建步骤。

```text
dist/                    网页文件与前端源码
  app.js                 界面、输入与本机保存
  data.js                配方、食材、价格与排序
  optimizer.js           收益优化与物料校验
  worker.js              后台计算
  progress.js            制作进度与备份校验
  sw.js                  离线缓存
  vendor/                HiGHS JS/WASM
scripts/                 本地运行与打包脚本
docs/                    算法与数据来源
licenses/                第三方许可证
test-optimizer.cjs       计算验证
```

修改 `dist/` 后刷新本地网页即可。更改缓存资源时，请同步更新 `sw.js` 中的缓存版本和文件清单。

运行验证：

```sh
npm test
```

验证覆盖整数规划与穷举比较、库存与土地限制、出售条件、加工余料和进度校验。算法细节见 [ALGORITHM.md](docs/ALGORITHM.md)。

欢迎提交 [Issue](https://github.com/VickieZhou/acnh-cooking-profit/issues) 或 Pull Request。报告配方或售价问题时，请提供料理名称、游戏版本、出售条件及实际数据；请勿公开个人备份文件。

## 计算范围

收益以输入条件和内置数据为准，部分价格仍待逐项实机核验。限时计算未证明最优时，界面会标明当前方案状态。

- 只计算料理与加工原料，不包含其他 DIY 家具或酒店兑换。
- 农田按每轮稳定收获计算，不扣除一次性种苗支出，也不估算初次生长与浇水时间。
- 「省制作批次」减少的是配方制作批次，不代表完整游戏操作耗时。
- 配方系列顺序参考社区 SerialID，不保证与所有游戏菜单的排序方式一致。
